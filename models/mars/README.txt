ZETA LEGACY — Mars model swap folder
=====================================

Drop a .glb here with one of these EXACT names and the game uses it automatically
(runtime-loaded; do NOT import — the editor importer is broken on this device):

  space_bike.glb  -> the hover-bike Alina rides on Mars
  crater.glb      -> scattered across the Mars surface as craters
  rock.glb        -> scattered as Martian boulders

Notes:
  - Size is auto-fit (centred + scaled), so any scale works.
  - Missing file => a procedural placeholder is used instead.
  - Animated/baked-animation models auto-play their animation.
  - Good free CC0 source: poly.pizza (Kenney "Spacecraft Speeder" is CC0).
    Download the GLB, rename to space_bike.glb, copy here.
